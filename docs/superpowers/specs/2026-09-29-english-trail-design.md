# 99天英语探险课程打卡网站设计

日期：2026-09-29

## 1. 目标

为上海五升六年级学生制作一个本地运行的英语听力课程打卡网站。课程以 British Council 为主，穿插 YouTube 英文动画与主题视频；在一个学期内完成 A1 核心训练并进入 A2 主线。

首版用于确认 UI、课程结构和交互效果，数据保存在本机浏览器。后续接入用户后台时保留现有课程和界面，只替换进度读写方式。

## 2. 时间范围

- 开始日期：2026-09-30
- 结束日期：2027-01-22
- 学习日：周一至周六
- 休息日：周日
- 法定节假日：照常安排课程
- 总学习日：99天
- 每日积分：5分
- 学期满分：495分

课程允许提前学习和补做。9月30日之前不显示课程，1月22日之后不安排课程。

## 3. 课程编排

采用螺旋进阶方式：儿童分级听力、连续剧情、精听复述、CEFR 分级训练、兴趣视频和周测并行推进。

### 3.1 四个阶段

| 阶段 | 日期 | 目标 |
|---|---|---|
| 起点与适应 | 2026-09-30—2026-10-27 | 完成听力诊断；学习 LearnEnglish Kids Level 3；完成 Starting Out 1–4；进入 A1 |
| A1核心训练 | 2026-10-28—2026-12-01 | 完成 Starting Out 5–10；系统训练生活场景 A1 听力 |
| A1完成与A2桥接 | 2026-12-02—2026-12-29 | 完成 Starting Out 11–15；完成 A1 重点内容；首次接触 A2 |
| A2主线 | 2026-12-30—2027-01-22 | 训练精选 A2 对话、留言、通知和解释；完成期末综合复习 |

### 3.2 每周节奏

- 周一：LearnEnglish Kids Level 3 或短故事
- 周二：Starting Out 新一集
- 周三：周二内容精听、跟读与复述
- 周四：A1 Listening，后期切换到 A2 Listening
- 周五：YouTube 英文动画或主题视频
- 周六：本周复习、词组回顾和小测
- 周日：休息

2026年9月30日至10月3日为四天启动单元，依次安排听力诊断、A1体验、兴趣视频和首次周测。最后一周安排周一至周五，并在1月22日完成期末总结。

每课预计25–35分钟，包含3–5项可核验任务。每个具体课程条目的下一行显示对应的可点击链接。

## 4. 外部资源策略

### 4.1 British Council

使用以下两个站点的公开学习材料：

- https://learnenglishkids.britishcouncil.org/
- https://learnenglish.britishcouncil.org/

课程页面不嵌入本站，也不获取账号、密码、Cookie或登录 token。课程卡片显示来源、内容说明和任务清单，并通过新标签页打开 British Council 原始页面。

### 4.2 YouTube

允许使用 YouTube 官方 iframe 播放器内嵌视频。播放器只在课程展开时加载，并同时提供“在 YouTube 打开”备用按钮。无法嵌入、被删除或受年龄限制的视频仍保留外部打开入口。

本地版必须通过 localhost HTTP 服务运行，不以 `file://` 方式打开，以降低 YouTube 因缺少来源信息而拒绝播放的概率。

### 4.3 内容边界

- 不复制、下载或重新托管第三方音视频。
- 不绕过站点的登录、地区、付费或 iframe 限制。
- 外部资源无法访问时，课程说明、任务状态和打卡功能仍正常工作。

## 5. 视觉与布局

选用“B1 · 温暖旅行手账”方向：

- 主色：米白、陶土红、森林绿和柔和金色
- 气质：旅行记录册、成长感、耐看，不做低龄卡通
- 桌面端：当天课程为主栏，旅程进度和本周路线为侧栏
- 手机端：自动改为单列，当天课程优先显示

页面主要区域：

1. 顶部标题、总积分和连续打卡天数
2. 当天课程摘要与任务完成进度
3. 任务清单、预计用时和资源入口
4. 四阶段旅程进度
5. 本周课程路线与提前学习入口
6. 全学期日期导航
7. 重置进度入口

## 6. 打卡与积分规则

- 当天所有任务勾选后，打卡按钮才可用。
- 每个学习日最多获得一次5积分。
- 总积分实时按“已完成课程数 × 5”计算，不单独保存积分值。
- 未来课程始终可打开、完成和打卡。
- 过去未完成课程可以补做并正常得分。
- 取消已完成状态时二次确认；确认后扣回对应5分，但保留任务勾选状态。
- 周日无课程，不影响连续学习天数。
- 积分仅累计展示，不提供兑换和消费功能。

## 7. 本地数据

首版使用浏览器 `localStorage` 保存：

- 各课程任务勾选状态
- 各课程打卡状态
- 打卡时间
- 数据格式版本号

课程内容为静态数据，不写入 `localStorage`。页面重新加载后恢复进度。更换浏览器、清理站点数据或更换设备不会自动同步。

后续接入后台时，保持课程数据和 UI 不变，只把 `loadProgress` 与 `saveProgress` 的本地实现替换为后台 API 调用。认证凭据只由未来后台安全管理，不进入前端源码。

## 8. 技术结构

首版使用原生 HTML、CSS 和 JavaScript，不使用前端框架或构建工具：

- `index.html`：语义化页面结构
- `styles.css`：响应式视觉样式
- `courses.js`：99天课程数据
- `app.js`：渲染、筛选、任务状态、积分和本地存储

该结构可以直接由任意静态 HTTP 服务器运行，也方便未来嵌入现有后台页面。

## 9. 异常处理

- `localStorage` 不可用：显示提示，本次会话仍可操作，但不承诺刷新后保留。
- 外部链接打不开：保留课程卡片和任务清单，不自动判定课程失败。
- YouTube iframe 加载失败：显示“在 YouTube 打开”备用按钮。
- 课程数据有误：控制台输出明确错误，并在页面显示数据校验失败提示。
- 重置全部进度：必须经过二次确认。

## 10. 数据校验与验收

启动时检查：

- 课程必须恰好99条。
- 日期必须唯一。
- 日期必须位于2026-09-30至2027-01-22。
- 日期不得为周日。
- 每课必须包含标题、来源、有效链接和非空任务清单。
- YouTube课程必须包含视频ID或有效外部链接。
- 总积分必须始终等于已完成课程数乘以5。

首版验收标准：

1. 电脑和手机宽度下均可正常使用。
2. 可以浏览全部99天，并快速返回今天。
3. 未来课程可以提前完成，过去课程可以补做。
4. 任务未全部完成时不能打卡。
5. 刷新页面后任务状态、打卡和积分保持一致。
6. YouTube使用内嵌播放器，British Council在新标签页打开。
7. 重复操作不会重复加分。

## 11. 首版不包含

- 用户账号和登录
- 多设备同步
- 后台管理界面
- 积分兑换和奖励商城
- British Council账号、密码或token处理
- 第三方音视频下载与本地托管
